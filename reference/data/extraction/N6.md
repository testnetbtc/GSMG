## 2. What these materials are

- **Provenance.** `parse_chat.py` converts a Telegram Desktop HTML export (`D:\tmp\gsmgio-5btc-puzzle\ChatExport\messages*.html`, a Windows path on the PR author's machine) into `=== [<date title attr>] <from_name>\n<text>\n\n` blocks [A:_pr93/_work/parse_chat.py@2c97f44]. It keeps only messages that have a `<div class="text">`; media-only messages, stickers, GIF/videos without caption and service messages are **dropped**. Sender is taken from the first `from_name` div in the message block, otherwise **inherited from the previous message** (`last_sender`). Links become `text [href]` (mentions appear as `@SoWut [https://t.me/SoWut]`; links with empty/identical href produce `[]`). FINDINGS.md describes `creator_jrk.txt` as "all creator messages" and `parse_chat.py` as "Telegram HTML export -> plain transcript" [A:_pr93/FINDINGS.md@2c97f44 section Tools]. The `.gitignore` notes a `cosmicduality.txt` OCR was excluded for copyright.
- **It is a derived (generated) text, not the primary export.** No numeric user IDs, no message IDs, no reply-to targets, no forward metadata other than what leaked into the sender name, no edit history, no media. Display names are unauthenticated (rule 5).
- **Chat identity.** Same group as the C dataset ("Telegram group "GSMG Puzzle Solvers", handle @SoWut, ids from the chat export" [C:content/sowut-data.js@caaa77a header]); see section 3 matching.
- **creator_jrk.txt** is byte-identical (46,152 chars of message blocks; file is 46,527 bytes on disk incl. encoding) to the subset of transcript messages whose sender string is exactly `Jrk Bgrt` (411 messages) -- N6 regenerated it from the transcript and compared: identical. It is therefore *not* "all creator messages": it omits Jrk's media-only posts (34 in-window per C), the 33 forwarded copies of Jrk messages, and anything Jrk may have posted under another name.
- **senders.txt** = top-35 sender counts; all 35 counts reproduce exactly from N6's parse. **hintgivers_names.txt** = the 25 distinct sender strings containing "Jrk" (exactly `Jrk Bgrt` plus 24 forward-tagged variants like `Jrk Bgrt 31.03.2019 19:55:41`).
