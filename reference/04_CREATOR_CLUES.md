## 3. The 2023-02-23 hint -- exact decode

Reverse the entire 1,288-bit string, regroup into bytes, read ASCII. This is equivalent to reversing byte order and each byte's bits. Output: 161 bytes, **no spaces**, SHA-256 `d13afe77dd6969a438e2020cc3df22e0e7d589ae88196caa9162c9168e25a018` (**reproduced** from [C:content/sowut-data.js@caaa77a id 8446]; also equals [B:_pr15/neo/materials/primary/hint_2023-02-23_decoded.txt@1e913fd]):

```text
yellowblueprimesmatrixsumlistlastwordsbeforearchichoiceyinyangwewontgiveawaythepassworditsinfrontofyoureyesbutyourenotseeingitverylaststepisatruegiveawaypromised
```

B's README and C print it with spaces and split words (`matrix sumlist`, `last words before archichoice`) [B:README.md@9e61693#L345-L350] [C:docs/CREATOR-INTEL.md@caaa77a H8]. Those spaces are **interpretation**. C attributes a spaced rendering to "the puzzlehunt README", which contains no 2023 hint at all [C:docs/WALKTHROUGH.md@caaa77a#L2035-L2043]. Byte offsets: the four leading labels are 16+13+26+7 = 62 bytes; the remaining text occupies bytes 62-160. [C:docs/LOOSE-ENDS.md@caaa77a#L463]'s "bytes 100-161" is wrong.
