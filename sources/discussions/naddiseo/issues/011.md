Moving these out of #10 so they don't get lost when it merges, as asked.

Revised down from what I first wrote in the PR thread. Two of the three I've since answered myself, so I'm only leaving what's actually still open.

**Withdrawn: raw Telegram history.** I found it. `halbgott29a/gsmgio-5btc-puzzle` has a 181k line `_work/chat_transcript.txt`. Anyone else stuck on the screenshots should start there rather than asking.

**Narrowed: local captures of gsmg.io.** The site is still live and still serving the original chain, so this is not the broad ask I made in the PR. `/theseedisplanted`, `/choiceisanillusion...` and `/89727c59...` all return 200 with the original content today, and the images are byte identical to archived copies. What would still help is anything that existed in 2019 or 2020 and is **no longer served**. A page that was up briefly and then removed wouldn't be in the live site or necessarily in the CDX index, and that's the only gap left here.

**Still open, and the one I care about: did Jrk ever plainly say whether the final step is derivable from published material alone?**

He has said things that read both ways. "Everything is solvable" points one way. The 2026-07-12 messages point the other: "my close friends have the best chance of solving it (a few tried), but they don't have the skills some of you do. NOTE: that is a hint." That reads like the last step depends on something he knows rather than something published.

This matters because three people working independently have now reached the same conclusion from different directions, that no function of the published artifacts produces the prize key. vadiksh85-pixel set it out in puzzlehunt/gsmgio-5btc-puzzle#82 and also made the structural point: `1GSMG1...` is a vanity address, so its key was brute forced and is random with respect to every artifact in the puzzle. A random key can't be the output of a derivation over those artifacts. I've reproduced that poster's committed matrix invariants exactly against my own decrypt (S=5193, Wr=268603, Wc=268828), so their data is sound.

If Jrk confirmed either way somewhere, a pointer to it would settle whether the remaining work is a cipher problem or a delivery problem. #82 asked essentially this and got no answer.
